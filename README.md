# E-Commerce-Online-Store-Project

## 📌 About

A TypeScript e-commerce store built with React, Redux, and Firebase. Includes product browsing, a shopping cart, checkout, and form validation.

## 🛠 Tech Stack

- **Framework:** React 18 + TypeScript
- **Build tool:** Vite
- **State management:** Redux Toolkit + React Redux + Redux Persist
- **UI libraries:** Chakra UI, Material UI (`@mui/material`)
- **Routing:** React Router DOM v6
- **Animation:** Framer Motion, Swiper (sliders)
- **Forms & validation:** Formik + Yup
- **Backend / Database:** Firebase
- **HTTP client:** Axios
- **Email:** EmailJS (`@emailjs/browser`)
- **Other:** React Icons, `node-telegram-bot-api` (dev tooling)

## ✨ Features

- Product listing and detail pages
- Shopping cart with persistent state
- Checkout flow
- Form validation (Formik + Yup)
- Firebase integration (auth / database)
- Responsive UI with Chakra UI and MUI
- Image sliders (Swiper) and animations (Framer Motion)
- Contact / email sending via EmailJS
